# 同步模板保留实例定制字段 + 模板库 MARK 真实命令预览

> 2026-08-13。状态：✅ 已完成（TDD 红→绿 + 构建/vet 通过）。

## 背景与痛点

1. **顽固痛点**：同步模板会覆盖掉实例已应用到节点的定制内容（如源 IP）。
   - 根因：`applyTemplateToInstance`（template_routes.go:659）将模板 13 个规则字段无差别覆盖实例（含模板空值清空实例有值）。用户实例化到多节点、各节点 IP 特化后，模板一更新点"同步模板"IP 即被模板默认值/空值覆盖。
2. **命令预览语义**：之前"规则命令预览"指的是**策略模板库中的 MARK 动作**。现状模板库 MARK 只展示意图描述（①②③中文），未展示真实 3 条 iptables 命令；且模板库与实例列表的命令预览逻辑重复（DRY 违规）。

## 用户决策（2026-08-13 确认）

1. **同步语义**：**保留实例非空字段**——模板空值不清空实例有值字段；模板非空始终覆盖
2. **模板库命令预览**：**仅编辑对话框**改真实命令，列表卡片不加（保持简洁）
3. **批量 sync-all**：保持全量（一键对齐语义，不引入字段选择）

## 方案

### 一、同步模板保留实例定制字段

**同步覆盖语义细化**：
- **字符串字段**（source/destination/source_group/destination_group/direction/protocol/port_range/nat_to）：模板非空 → 覆盖实例；模板为空 → **保留实例当前值**（不覆盖不清空）
- **数值字段**（group_id/mark/match_mark/priority）：模板值直接覆盖（含 0；priority/mark 总有合法值，模板侧即为权威）
- 同步后 `Applied=false` + `SyncedSpecVersion/SyncedTemplateUpdatedAt` 更新到模板最新（用户已主动处理模板变更，drift 消失）

**后端**（`template_routes.go`）：
- `applyTemplateToInstance` 字符串字段改用 `orKeepString(cur, tpl)`（tpl 非空返回 tpl，否则返回 cur）；数值字段保持直接覆盖
- 新增 `syncOverrideFields(inst, tpl) []string`：返回**同步时实际会被模板覆盖**的字段（字符串字段要求模板非空且与实例不一致；数值字段直接比不等）——供 sync-preview 展示真实"将覆盖"清单，避免误导（模板空值字段不会出现在预览里）
- `sync-preview` 路由改用 `syncOverrideFields`
- `sync` / `sync-all` 均走新 `applyTemplateToInstance`（语义一致）
- 注意：这是对漏洞 E 修复（"模板字段清空传播"）的有意回调——**模板清空字段不再传播到有值实例**（实例特化优先）。在注释与方案中明确记录此权衡

**前端**（`NodePolicies.vue`）：
- `handleSync` 逻辑不变（sync-preview 展示 + confirm），预览内容已由后端过滤为真实覆盖字段
- 确认框文案补一句："模板空值字段将保留实例当前值(如源 IP)"

**测试**（红→绿）：
- 改 `TestSyncInstanceFullOverwrite`：模板 Source 为空 → 实例 Source **保留** "1.1.1.1"（原断言为空，反转）
- 新增 `TestSyncKeepsInstanceNonEmptyWhenTemplateEmpty`：模板 source/port_range 空、实例有值 → 保留；模板 source 非空 → 覆盖；数值字段 mark/priority 模板值覆盖
- 改 `TestSyncInstancePreview`：预览只返回实际覆盖字段（模板空值字段不出现）
- `TestSyncAllInstances`：模板 source 非空不受影响（保持）

### 二、模板库 MARK 真实命令预览（仅编辑对话框）

**抽离共用纯函数**：
- 新建 `web/src/composables/useCommandPreview.js` 导出 `buildCommandPreview(f, chains)`（从 NodePolicies.vue 迁移，逻辑不变：MARK 3 条真实命令 / 其余单条）
- NodePolicies.vue 删除本地 `buildCommandPreview`，改 import 共用（行为不变）

**TemplateLibrary.vue**：
- 编辑对话框 `previewCommand`：MARK 分支改为**真实 3 条 iptables 命令**（复用共用 buildCommandPreview），顶部保留一行意图说明（"MARK 白名单 = 打标 → 白名单放行 → 兜底 DROP"）；非 MARK 分支复用共用函数
- 列表卡片不加命令预览（用户决策）
