# 自动建库 + 模板库导入导出 + YZINFO 模板

## 摘要
三个模块：自动建库（开箱即用）、模板库导入导出（迁移/备份/初始化）、YZINFO 存量脚本分析生成模板文件。

## 决策
- 自动建库：`internal/db/db.go` 新增 `ensureMySQLDatabase()`，driver=mysql 且 `MYFW_DB_AUTOCREATE!=false` 时自动 `CREATE DATABASE IF NOT EXISTS`，SQLite 跳过
- 模板库导入导出：JSON 格式，手动触发，默认 skip 冲突策略，Mark→CustomChain→PolicyTemplate 依赖顺序，单事务
- 入口：API 优先（`GET/POST /api/v1/templates/export|import`），无 CLI（避免过度设计）
- YZINFO：复用内置 `business-input` + `mark-mangle` 策略组，不新建 CustomChain，不扩展 DOCKER-USER
