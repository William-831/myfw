# dispatch applied 修复 + 节点 248 证书吊销排查

日期：2026-08-07

## 问题

1. 节点模板库应用模板下发、节点策略新增下发均报错：
   `dispatch: rpc error: code = FailedPrecondition desc = node n_928ff... not connected`
2. 节点策略状态却显示"已下发"。

## 根因分析

### 问题一：applied 乐观标记（已修复）

`POST /nodes/:id/dispatch` 路由在 `co.Submit()` 后立即执行：
```go
db.Model(&model.NodePolicyInstance{}).Where("node_id = ?", nodeID).Update("applied", gorm.Expr("enabled"))
```
无论 Agent 是否在线、下发是否成功，`applied` 都被置为 `true`，前端误显示"已下发"。

同时 `coordinator.go` `Submit()` 吞掉 `approveAndDispatch()` 的错误（只 log 不返回），调用方无感知。

### 问题二：节点 248 证书被吊销（已修复）

Agent 日志循环 `certificate revoked`。根因是 248 用的是旧版 Agent，CertRotation KeyDir bug：
- KeyDir=`/var/lib/myfw-agent/`（旧版），续签新证书写到该目录，吊销旧证书
- conn.Dial 读 `/etc/myfw-agent/agent.crt`（旧证书，已吊销）

数据库 certificates 表验证：248 有两条记录，旧证书(serial=18CCE...)revoked=1，新证书(serial=97CD9...)revoked=0。

## 修复

### 代码修复（coordinator.go + template_routes.go）

1. `handleResult()`：Agent 确认成功时 `applied = enabled`，失败时 `applied = false`
2. `POST /nodes/:id/dispatch`：移除乐观 `applied = enabled` 更新
3. `Submit()`：收集 `approveAndDispatch()` 错误，返回给调用方（不再吞错）

### 部署修复（248 节点）

1. 临时：`cp /var/lib/myfw-agent/agent.{crt,key} /etc/myfw-agent/` 覆盖旧证书，重启 Agent 恢复连接
2. 根本：交叉编译最新 Agent（含 KeyDir 修复），`systemctl stop` -> 替换二进制 -> `start`

## 产出路径

- `internal/controller/task/coordinator.go`：handleResult + Submit
- `internal/controller/server/template_routes.go`：dispatch 路由
- 远程 248：`/usr/local/bin/myfw-agent` 已更新
- 远程 249：`myfw-controller` 容器已更新重启

- 248 Agent 日志：`stream opened` + `iptables rules reported successfully`，无 `certificate revoked`
- 249 Controller 日志：`agent stream connected` for n_928ff...
