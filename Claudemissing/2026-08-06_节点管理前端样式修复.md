# 节点管理前端样式修复

## 摘要
修复节点管理页面三个样式/展示问题：IP 地址换行、最后活跃时间默认折叠、主机名改用节点名称。

## 三个问题与决策

### 问题1：IP 地址换行
- **决策**：IP 列加 `show-overflow-tooltip`（与节点名称列一致），列内单行不换行，超长悬浮显示完整地址。

### 问题2：最后活跃时间默认折叠
- **决策**：`columnVisible.lastSeen` 默认值 `true` -> `false`，该列默认隐藏，需要时在"列设置"勾选展示。

### 问题3：节点名称代替主机名（需后端配合）
背景：`Node` 原无 `Name` 字段，添加节点时填的名称只存于 `BootstrapToken.Note`，注册时未写入节点，列表"主机名"实为 Agent 上报的机器名。

- **后端**：
  - `model.Node` 加 `Name string` 字段（GORM AutoMigrate 自动加列）
  - `registration.go` 注册时 `Name: tok.Note`（token note 即用户填的名称）
  - `node_routes.go` PUT 接口加 `name` 字段更新支持
- **前端**：
  - 列表第一列：`hostname`/主机名 -> 节点名称（`row.name || row.hostname`，旧节点回退主机名）
  - 编辑对话框：主机名 -> 节点名称，`editForm.hostname` -> `editForm.name`
  - 详情对话框、快速诊断标题、审批/续签/删除确认弹窗：优先 `row.name`
- **边界**：旧节点 `name` 为空时回退显示主机名，避免历史节点空白；如需统一可删除重建。
