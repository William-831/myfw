# 2026-08-10 审计日志/审批中心非本人操作排查

## 摘要
用户未操作电脑，但审计日志与审批中心出现"前两天"的操作内容。查库确认根因：**drift 自愈机制产生 system/agent 名义的自动任务与审计记录**，且自愈任务走保护期导致"自愈→超时回滚→再漂移"死循环。

## 查库证据（249 /home/myfw/data/myfw.db）
- audit_logs 共 917 条（08-06 ~ 08-10）
- **node.drift 684 条**（actor=agent，8月7 占 679）
- **system task.submit 7 条 + task.approve 7 条**（8月7 2 次 + 8月9 5 次）
- **task.auto_rollback 8 条**（actor=system，每次 submit 后正好 5 分钟）
- node.auto_reregister 2 条（8月6，DB 重建）
- tasks 表：7 条 system 任务全部 rolled_back

## 根因链条
1. **8月7 12:26 本地**：admin 手动回滚 t_e5121df4 失败（`Couldn't load target MYFW-MARKACL-IN`，Snapshot/Restore 组链 bug）→ 规则半残 → watchdog 开始每 30s 报 drift
2. **8月7 04:26-09:26 UTC**：旧 Controller（无 OnSync）只记 drift 不 Apply → 679 次 drift 记录
3. **8月7 09:27 UTC**：部署新 Controller（含 OnSync drift 修复）
4. **8月7 09:29 UTC**：drift 自愈触发 2 次 system submit/approve → 5 分钟保护期超时 → 09:34 auto_rollback
5. **8月9**：自愈死循环（submit→apply→5min保护期超时→rollback→恢复快照≠expected→再drift→再submit），共 5 次

## 机制缺陷（为什么循环）
- `server.go:146` OnSync → Submit(Author=system, AutoApprove=true) → 进 confirm_wait 保护期
- 无人确认 → `coordinator.go:482` autoRollback → Agent 恢复 apply 前快照
- Agent OnRollback（handler.go:156）**恢复快照后不 SetExpectedHash** → 实际≠expected → 30s 后 watchdog 再 drift → 循环
- watchdog（watchdog.go:107）**无任何限流**，每 30s 漂移即发 Sync

## 展示漏洞
1. drift 自愈任务 policy_name="节点策略下发"、actor=system，与人工任务无法区分
2. task.submit/approve 审计 scene=normal（常规场景），非特殊场景标记
3. 审批中心 Approve.vue 不区分系统/人工任务

## 修复（2026-08-10 完成，全做）
1. **AutoConfirm 机制**（model/task.go + coordinator.go）：Task 加 AutoConfirm 字段；SubmitOpts 加 AutoConfirm/Scene；handleResult 对 AutoConfirm 任务 apply 成功直接 confirmed（发 Confirm 释放 Agent 快照，审计 scene=self_heal），不进 confirm_wait 保护期——根治自愈死循环
2. **OnSync 自愈即下即确认**（server.go）：OnSync 用 AutoApprove+AutoConfirm+Scene=self_heal
3. **OnSync 去重**（coordinator.go HasInFlight + server.go）：节点有在途任务时跳过 Submit
4. **OnRollback 更新 expected**（handler.go）：lastHash 存 apply 前快照 hash，回滚恢复后 SetExpectedHash(快照 hash)，杜绝回滚后被判 drift
5. **审计 scene 区分**（model.AuditSceneSelfHeal）：自愈任务 submit/approve/applying_ok 全部标 self_heal
6. **前端区分**（Audit.vue/Approve.vue）：scene 筛选加"系统自愈"、actor=system 显示🤖、审批中心审批人列/策略列标注自愈
