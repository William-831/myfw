# 单条策略流量预演抽屉方案

> 2026-08-12。状态：✅ 已完成（2026-08-13 实现 + 构建通过）。

## 背景

当前流量预演为节点级大按钮 + Dialog（`NodePolicies.vue:47,100-153`），需先选节点、填五元组、看 steps 列表。问题：预演与具体策略脱钩，用户难以对照"这条策略的预期"与"实际匹配路径"。

## 目标

- 去掉节点级"流量预演"按钮
- 每条策略实例下方加预演图标按钮，点击弹抽屉
- 抽屉左右对比：左"你的预期目标"，右"实际模拟过程和结果"
- 右侧流程图为通道式可视化：浅灰网格底纹 + CSS 动画光点从左到右移动；遇放行变绿光，遇拦截变红光并停止

### 2. 左侧"预期目标"

展示被预演实例的定义 + 预期结论：

```

源: 192.168.1.5   目的: 任意

      → 被 ACCEPT 放行
```

- MARK 动作特殊文案："打标 → 由 MARKACL 白名单链放行（非白名单源兜底 DROP）"
- 预填 flow 从 inst 反推（见脚本逻辑）

### 3. 右侧"实际模拟"通道流程图

**结构**：
```
[入口] → [step1: MYFW-MARKMANGLE / MARK ✗] → [step2: MYFW-MARKACL-FWD / ACCEPT ✓] → 终点
```

- steps 横向排列成一条通道
- 每个 step 节点：chain（小字）+ rule_id + action 标签 + matched 状态
- matched=true 的节点高亮（边框 + 背景）
- 终点节点显示 verdict（ACCEPT 绿 / DROP 红 / PASS 灰）

**通道视觉**：
- 浅灰底 `#f5f7fa`
- 网格底纹：`repeating-linear-gradient` 横竖细线，营造"通道"感
- 光点（`.sim-pulse`）：圆形发光体，CSS keyframes 从左 translateX 到右
- 动画语义：
  - 默认：光点 2s 内从左滑到右
  - verdict=ACCEPT：光点到达终点变**绿光** + 通道边框泛绿
  - verdict=DROP/REJECT：光点停在命中终止的 step 位置，变**红光** + 通道边框泛红，动画停止
  - verdict=PASS：光点走完全程变灰（无规则命中）

**停止位置精确控制**：
```css
.sim-channel {
  --stop-x: 100%; /* 默认走到底 */
}
.sim-channel.is-drop { --stop-x: var(--hit-x); } /* 命中 DROP 的 step 位置 */
.sim-pulse {
  animation: flow-run 2.4s cubic-bezier(.4,0,.2,1) forwards;
  /* 终点 = var(--stop-x) */
}
@keyframes flow-run {
  from { left: 0; }
  to   { left: var(--stop-x); }
}
```
`--hit-x` 由 JS 根据命中终止 step 的索引占比计算（`hitIndex / (steps.length) * 100%`）。

### 4. 脚本逻辑

**新增 `openInstSimulate(inst)`**：
```js
const simInst = ref(null)
function openInstSimulate(inst) {
  simInst.value = inst
  // 从实例反推五元组预填
  simForm.direction = inferDirection(inst)       // 见下
  simForm.source_ip = pickFirstIp(inst.source)   // CIDR 取首个 / 单 IP 直接用
  simForm.dest_ip   = inst.destination || ''
  simForm.protocol  = (inst.protocol || '').toLowerCase()
  simForm.dst_port  = parseFirstPort(inst.port_range) // "22"->22, "1000-2000"->1000
  simForm.src_port  = 0
  simForm.mark      = 0
  simResult.value = null
  simVisible.value = true
}
```

**`inferDirection(inst)`**：
- 查 `customChains` 找 `inst.group_id` 对应链的 `mounts`/`parent`
- 若 parent 含 INPUT → INPUT；含 FORWARD → FORWARD；否则默认 FORWARD
- 简化兜底：默认 FORWARD（多数业务场景）

**预期动作文案 `expectedText(inst)`**：
```js
function expectedText(inst) {
  const a = (inst.action || '').toUpperCase()
  if (a === 'MARK') return '打标 → MARKACL 白名单链放行(非白名单兜底 DROP)'
  if (a === 'ACCEPT') return '放行(ACCEPT)'
  if (a === 'DROP') return '拦截(DROP)'
  if (a === 'REJECT') return '拒绝(REJECT)'
  return a
}
```

**命中终止 step 索引**（驱动 `--hit-x`）：
```js
const hitStopIndex = computed(() => {
  if (!simResult.value?.steps?.length) return -1
  const v = simResult.value.verdict
  if (v === 'ACCEPT' || v === 'DROP' || v === 'REJECT') {
    // 最后一个 matched=true 的 step 即终止点
    let idx = -1
    simResult.value.steps.forEach((s, i) => { if (s.matched) idx = i })
    return idx
  }
  return -1 // PASS:走完全程
})
const hitX = computed(() => {
  const n = simResult.value?.steps?.length || 1
  if (hitStopIndex.value < 0) return '96%'
  return `${(hitStopIndex.value + 1) / n * 100}%`
})
```

### 7. 边界

- 实例无 source（任意源）：预填 source_ip 留空，用户可填具体 IP 看匹配
- MARK 实例无源骨架：预填 source_ip 留空，提示"填白名单源 IP 看放行 / 填非白名单看 DROP"
- steps 为空（无规则参与）：通道显示"无规则参与匹配"占位，不播放动画
- direction 推断失败：默认 FORWARD + 表单可改

## 不做

- 不改后端 simulator（Evaluate 纯函数已满足，单条策略预演仍走全集匹配--这是"预期 vs 实际"对比的核心价值：实际可能被更高优先级规则抢先命中）
- 不改 simulateFlow API
- 不加前端单元测试（纯 UI 交互 + CSS 动画，项目前端无 Vitest 配置；预填纯函数 `pickFirstIp/parseFirstPort` 逻辑简单，必要时可补）
